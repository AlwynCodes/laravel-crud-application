LABORATORY NO. 4 — INSTALLATION

This folder is the complete, tested version of laravel-crud-application with all
four enhancements from the lab sheet:

  1. Server-side validation (Form Requests + per-field errors)
  2. Product image upload, replacement and deletion
  3. Role-based authorization (admin / user)
  4. Search + pagination

It keeps your original structure: `qty` column, `product.*` route names,
blue/amber Tailwind pages.

------------------------------------------------------------------
INSTALL (PowerShell, inside C:\Users\alwyn reuyan\laravel-crud-application)
------------------------------------------------------------------

1. Back up your current work first (git commit), then copy these files over your
   project folder — overwrite when asked. Keep your own `.env` and `vendor`
   folder; they are not included here.

2. Run:

       php artisan migrate:fresh --seed
       php artisan storage:link
       php artisan optimize:clear
       npm run build          (only needed if you change CSS/Blade classes)

3. Start the server:

       php artisan serve

4. Log in with:

       admin@example.com   / password    (can create, edit, delete)
       user@example.com    / password    (can only browse)
